# Peter Schuppisser, landing page

Site statique simple, prêt à publier, créé à partir des visuels fournis.

## Fichiers

- `index.html` : structure de la landing page
- `styles.css` : styles responsive, minimalistes et premium
- `cover peter schuppisser.png` : image hero
- `inside peter schuppisser.png` : image de section œuvres

## Ouvrir localement

Double-cliquer sur `index.html` ou servir le dossier avec un serveur statique.

Exemple :

```bash
cd "/Users/openclaw/Downloads/site peter schuppisser"
python3 -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.
